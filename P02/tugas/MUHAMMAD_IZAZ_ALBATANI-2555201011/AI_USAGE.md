# AI Usage — P02

## 1. Alat Bantu yang Digunakan

Dalam mengerjakan praktikum Pemrograman Berorientasi Objek (PBO) Pertemuan 2, saya memanfaatkan ChatGPT sebagai sarana pendukung untuk mempelajari konsep dan memahami implementasi kode Python.

## 2. Tujuan Pemanfaatan AI

Penggunaan AI bertujuan untuk membantu memahami penerapan konsep OOP, menyusun kelas beserta atribut dan metodenya, serta mempelajari cara menguji program menggunakan alat pengujian otomatis.

## 3. Bentuk Bantuan AI

ChatGPT digunakan untuk membantu beberapa bagian pekerjaan, antara lain:
- Memahami susunan direktori dan berkas dalam proyek P02.
- Mempelajari penerapan kelas `Penyewa`, `AlatTani`, dan `Petugas`.
- Memahami penggunaan atribut, metode, dan type hint pada Python.
- Menyusun serta memahami unit test untuk memeriksa fungsi setiap kelas.
- Mendapatkan panduan menjalankan program dan melakukan pemeriksaan kode menggunakan pytest, mypy, serta checker PBO.
- Memahami tahapan pengelolaan branch Git sebelum mengirimkan perubahan melalui Pull Request.

## 4. Pengujian dan Pemeriksaan

Setelah kode disiapkan, saya menjalankan pemeriksaan secara langsung melalui terminal. Hasil pengujian menunjukkan bahwa 10 unit test berhasil dijalankan, pemeriksaan mypy tidak menemukan masalah tipe data, checker PBO dinyatakan lolos, dan program utama dapat dijalankan dengan baik.

## 5. Tanggung Jawab Penggunaan AI

Saya menggunakan AI sebagai pendamping dalam proses pembelajaran. Setiap kode dan hasil pengujian tetap perlu saya periksa dan pahami agar sesuai dengan kebutuhan praktikum. Saya bertanggung jawab atas hasil pekerjaan yang dikumpulkan serta memahami cara kerja program yang telah dibuat.
