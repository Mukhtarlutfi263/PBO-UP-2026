# Refleksi P01

## Kasus Nyata di Kampar

Dalam kehidupan sehari-hari di Kabupaten Kampar, pendataan mahasiswa dapat dilakukan menggunakan program sederhana. Data seperti nama, NIM, dan desa asal dapat disimpan sebagai objek agar lebih terstruktur dan mudah dikelola.

Pada tugas P01, saya membuat kelas `Mahasiswa` untuk menyimpan nama, NIM, dan desa asal. Setiap objek mahasiswa memiliki data sendiri, sedangkan metode `perkenalan()` digunakan untuk menampilkan informasi mahasiswa dalam bentuk kalimat.

Dari latihan ini, saya memahami bahwa pemrograman berorientasi objek membantu menyusun data dan perilaku dalam satu kelas. Dengan begitu, program lebih mudah dibaca, dikembangkan, dan dipelihara.
