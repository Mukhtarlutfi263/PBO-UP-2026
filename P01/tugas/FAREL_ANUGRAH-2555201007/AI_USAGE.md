# AI Usage

Dalam pengerjaan tugas P01, saya menggunakan ChatGPT sebagai alat bantu untuk memahami struktur program Python dan memperbaiki masalah saat menjalankan modul menggunakan perintah `python -m src.main`.

Bantuan AI digunakan untuk:
- Memahami cara mengimpor kelas `Mahasiswa` dari modul Python.
- Menyusun file `src/main.py` sebagai titik masuk program.
- Memahami struktur folder tugas dan cara menjalankan program dari direktori yang tepat.

Saya tetap memeriksa kode dan menjalankan program untuk memastikan hasilnya sesuai dengan kebutuhan tugas. Program menampilkan nama, NIM, dan desa asal mahasiswa melalui metode `perkenalan()`.

AI digunakan sebagai alat bantu pembelajaran, bukan sebagai pengganti pemahaman dan pemeriksaan mandiri.
