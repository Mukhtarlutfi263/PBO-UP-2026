\# Refleksi P03



Pada P03, saya mempelajari enkapsulasi pada Python melalui penggunaan property dan setter. Saya memahami bahwa setter dapat digunakan untuk memvalidasi data sebelum disimpan sehingga objek lebih aman dari nilai yang tidak sesuai.

Dibandingkan P02, kode pada P03 menjadi lebih panjang karena adanya property, setter, validasi, dan value object. Sebagai gantinya, data dalam objek menjadi lebih terkontrol dan kesalahan input dapat dicegah.
